# Model credits

**endurance.glb** is derived from
["Interstellar | Endurance"](https://skfb.ly/p6vzT) by
[devPilot](https://sketchfab.com/devPilot), licensed under
[Creative Commons Attribution 4.0](http://creativecommons.org/licenses/by/4.0/).

Changes from the original: converted from FBX to glTF (FBX2glTF), the colour
texture embedded, metalness and roughness adjusted for this scene's lighting,
Draco mesh compression applied (gltf-pipeline). At run time the clock scales
and rotates the model into its frame and splits the hull into twelve sectors so
the current hour's module can light up; the geometry itself is unchanged.

The Endurance is a design from the film *Interstellar* (2014). This model is a
fan recreation; no affiliation with the film's rights holders is implied.
