Endurance Clock

The ring of the Endurance as a clock, embedded transparently over a page. Scroll down for a second, self-contained instance.

How this page embeds it

<link rel="stylesheet" href="/css/endurance-clock-3d.css">
<script type="importmap">{ "imports": { "three": "…/three.module.js", "three/addons/": "…/examples/jsm/" } }</script>

<div class="hero__clock" data-endurance-clock-3d data-transparent data-readout="false"></div>
<script type="module" src="/js/endurance-clock-3d.js"></script>

Or mount by hand: import { mount } from '/js/endurance-clock-3d.js'; const clock = mount(el, { transparent: true }); The widget fills whatever size its container has, pauses when scrolled out of view, and clock.destroy() removes it.
